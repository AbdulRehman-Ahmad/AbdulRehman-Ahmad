### BayanAI — Speak Your Khata

**A voice-controlled credit ledger and inventory app for karyana shopkeepers.** A shopkeeper can speak a transaction in Urdu, Roman Urdu, or English. The app transcribes it, converts it into structured commands, and asks for confirmation **before** updating customer balances and stock.

- **Mobile:** Flutter, Firebase Authentication, Cloud Firestore
- **AI backend:** Python, FastAPI, faster-whisper (Whisper), Ollama, Qwen 2.5
- **AI workflow:** Speech recognition → LLM-based command extraction → editable confirmation → database updates
- **Data integrity:** Atomic Firestore updates, per-shop security rules, input validation
- **Team:** Built with Muhammad Monam Majeed and Nimra Shahid

> The AI backend runs locally for the prototype. It is not presented as a production-hosted service.
