### BayanAI — Speak Your Khata

**A voice-powered ledger and inventory application for local karyana shopkeepers.** Instead of manually recording credit transactions in a notebook, shopkeepers can speak in Urdu, Roman Urdu, or English. BayanAI transcribes the request, extracts structured actions, and displays them for confirmation before updating balances and stock.

| Component | Implementation |
| --- | --- |
| Mobile application | Flutter, Firebase Authentication, Cloud Firestore |
| AI service | Python, FastAPI, faster-whisper, Ollama |
| Language processing | Open LLM (Qwen2.5 default), structured command extraction |
| Data integrity | Confirmation-before-save, atomic Firestore updates, user-scoped security rules |
| Supported operations | Credit entries, repayments, sales, restocking, and transaction history |

**Built with Muhammad Monam Majeed and Nimra Shahid.** The AI service runs locally in the prototype; the project is not presented as a production-hosted service.
